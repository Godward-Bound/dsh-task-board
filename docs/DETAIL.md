# dsh-task-board · 任务卡看板

## 它做什么

工作区的卡目录（Config.cardsDir）下每张卡是一个 Markdown 文件，一条写给 agent 的一次性任务指令。
卡多了之后「跑没跑、跑到哪、结果在哪」只能靠人翻目录。这个工具一条调用把现状摆成一张表。

## 工具 `task_board`

| 参数 | 值 | 行为 |
| --- | --- | --- |
| `what` | `list`（默认） | 全量一张表，按 mtime 倒序 + 三行汇总 |
| `what` | `detail` | 传 `name`：目标一句话、状态、报告前 20 行、没打勾的验收项 |
| `what` | `stale` | 超过 `staleDays` 天没动、又没报告的卡（「写完了没人跑」） |
| `what` | `template` | 输出一张可直接落盘的卡骨架（空看板时从这里开始） |

## 卡的格式

- 文件名：`_任务卡-<名字>.md`（可用 `filePattern` 改成你自己的命名约定）。
- 头部一行状态：`> 状态：未开工`（或 `在跑` / `做完，见 _reports/xxx.md`）。
- `## 0 一句话目标` 段的首行 = 看板上显示的目标。
- `## 验收` 段里的 `- [ ]` 行 = 未打勾的验收项。
- `## 输出`（或 `## 交付`）段里的第一个 `.md` 路径 = 报告位置。

不确定怎么起手就调 `what=template`，拿到的骨架可以直接写进文件。

## 状态判定（优先级，命中即停）

1. 卡头 40 行里有 `> 状态：…` 行 → **照抄正文，不解释**（这是事实）。
2. 没有状态行，但卡里输出/交付段写的第一个 `.md` 报告文件**确实存在** → `有报告，待核对`（推断）。
3. 都没有 → `未开工`（推断）。

**推断出来的状态渲染时加 `?` 后缀**——看板不把推断混成事实。要消除 `?`，往卡里补一行
`> 状态：做完，见 _reports\xxx.md`（补状态行是写操作，不在本工具职责内）。

## Config

| 项 | 默认 | 说明 |
| --- | --- | --- |
| `workspaceRoot` | 空 = 跟随当前工作区（cwd） | 相对路径的解析锚点 |
| `cardsDir` | `tasks` | 卡目录，相对 `workspaceRoot`（绝对路径也认） |
| `filePattern` | `^_任务卡-.+\.md$` | 卡文件名过滤正则（字符串，不带首尾斜杠） |
| `staleDays` | `3` | stale 的天数线 |
| `autoInject` | `true` | 新会话开场注入开关 |
| `autoInjectChars` | 600 | 注入文本预算（超长截断加 `…`） |
| `autoInjectOrder` | 900 | 注入段在系统提示里的排序 |

## 斜杠命令与开场注入

- `/board [list|stale|detail|template] [卡名]`：宿主侧直接执行 `task_board` 的**同一条实现路径**（`runBoard`，工具与命令共用），结果不进模型历史、不烧 token。detail 缺卡名、卡不存在都会给 error 文本而不是抛异常。headless / 老宿主没有 commands 服务时自动跳过（日志一行），工具不受影响。
- **新会话开场注入**（默认开，`autoInject=false` 关）：每个新会话第一轮注入一段看板快照——卡总数与 未开工 / 在跑 / 做完 / 卡住 分布（按状态行关键字 + 推断归类）。卡目录没就绪就留到下次再注入；磁盘与端口由 env-doctor 的注入段负责（跨包不重复实现同一逻辑）。每次成功注入在日志留 `auto-inject session=<id> chars=<n>`。
- **常驻提示**：`systemPrompt.context` 注册 task_board 自己的触发词段（env-doctor 已注册覆盖两个工具的完整版本，单独安装本插件时本段依然成立）。

## 实现边界

- 只用 Node 内置模块，零依赖；纯 `readFileSync`/`statSync`，不起子进程，单次调用 < 1 秒。
- 只读：不写卡、不写报告、不建目录。
- 返回文本超 4KB 按整行截断（detail 报告预览 20 行也可能触发）。
- 状态行只在头部 40 行找；报告路径扫输出/交付**全文**——因为交付段实际常落在 40 行外，按 40 行抓常常一个都抓不到，故放宽为整卡。
- 目标一句话取 `## 0 一句话目标` / `## 0. 一句话目标` / `## 目标` 段首行；
  报告路径取 `## 8 输出` / `## 输出` / `## 5 交付` / `## 输出（四段）` 等变体段里的第一个 `.md`。
- 卡目录不存在时返回「怎么改 config」的引导而不是异常；`filePattern` 编译失败同理。
